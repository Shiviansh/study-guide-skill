# Mode recipes

Section order for each mode. Every mode starts with the cover box and a contents list.

## quiz
1. Quick Revision — 40+ one-liners per unit (facts, dates, numbers, definitions, formula in words).
2. Unit sections — concise: bullet explanations, key figures, boxed formulas, Exam-focus and Trap boxes. Short derivations only where a formula's form is commonly asked.
3. Formula sheet · Numbers to remember · Common traps (25+).
4. Rapid-fire bank: `<table class="rf">` rows of "question → answer" (150–300 rows), grouped by topic, so the student can cover the answer column and self-test.
5. Practice MCQs (50+), 4 options each, plausible distractors built from real confusions (wrong slope, swapped regulator, off-by-factor formula). Answer key table with a one-line reason per answer.
6. A handful of 1-step numericals presented as MCQs.

## midterm
1. Quick Revision one-liners per unit.
2. Unit sections in full: explanation → figure → boxed formula → numbered derivation chain → worked example → Exam-focus / Trap / Extra boxes. Comparison tables for anything that comes in "types".
3. Formula sheet (grouped by unit) · Numbers · Traps.
4. Question bank: `.q` blocks with "[N marks]" and a `.mans` model-answer outline (what to write, which figure to draw, which derivation steps). 8–12 per unit, mixing define/explain/compare/derive.
5. Solved numericals (5+ per unit) with every step and units.
6. Optional short MCQ / one-liner section at the end for last-minute revision.

## endterm
Midterm recipe over **all** units, plus:
- Merge earlier guides for the course from the library (`src/` fragments), de-duplicate, renumber sections.
- One unified formula sheet / numbers / traps across the course.
- Question bank organised by unit; earlier quiz MCQs appended as "Practice MCQs".
- Cover lists every unit and which decks fed it.

## notes
Unit sections in full (midterm depth) + formula sheet + traps. No question bank unless asked.

## cheatsheet
2–4 pages, two-column feel: formulas (boxed, grouped), numbers table, traps, 30–60 one-liners. No figures except one or two that are themselves the formula (e.g. a classification tree).

## Revision plan (any mode, when an exam time is mentioned)
Add a small table on the cover: block → what to read → time. Front-load high-weight units and anything with derivations; finish with formula sheet + traps + question bank.
